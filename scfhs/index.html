Ingestion: Fivetran is worth evaluating

Fivetran has been available on Google Cloud in Dammam since June 2026. It could replace both Datastream and the custom connectors. Three points need answers before choosing it.

1Data residency: which plan keeps processing in Dammam, and where are the control plane, logs and metadata stored?
2Data freshness: one-minute syncs require the Enterprise plan or higher. Latency in seconds requires Fivetran HVR.
3Cost: pricing is based on monthly active rows, so the quote should use actual SCFHS volumes.

Using Fivetran moves the dependency from Google to Fivetran. We suggest keeping the Bronze layout independent of Fivetran, so it can be replaced later without changes to Silver or Gold.

Everything as code in GitLab

Infrastructure, pipelines, dbt models, tests, access policies and metrics are kept in one repository and deployed through CI/CD. The same build is promoted from dev to staging to production.

Promote one buildOnly the environment settings differ between dev, staging and production.
No manual changes in productionEmergency access is time-limited and logged.
Secrets stay out of GitCode refers to Secret Manager entries by name.

├─ ingestion/   Fivetran or Datastream config, dlt pipelines
├─ dags/        Airflow schedules
├─ dbt/         Bronze → Silver → Gold models, tests, contracts, metrics
├─ ai/          embedding job and index settings
└─ config/      dev / staging / prod, the only files that differ

Exit plan

Most components can be moved by copying data or redeploying the same code. The main effort is SQL written specifically for BigQuery. To keep it low, we recommend dbt cross-database macros, no BigQuery-only features in the core pipelines, a nightly copy of Bronze to SCFHS storage, and a yearly exit test.
